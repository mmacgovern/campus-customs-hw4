# Campus Customs front end

React + Vite + TypeScript. See `../README.md` for setup.

```powershell
npm install
npm run dev      # http://localhost:5173 (needs the back end on :8000)
npm run build    # type-check + production build into dist/
npm run lint     # oxlint
```

Key files: `src/App.tsx` (routes), `src/api.ts` (all calls to the back end), `src/components/ChatPanel.tsx`, `src/pages/`.
